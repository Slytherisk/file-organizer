# File Organizer 

## A simple python script for organizing your files.

---

## Requirements

- Python 3.x
- No external libraries required

---

## How does it work?

- Run the script in a specific folder.
- Python code creates folders and moves files into them depending
  on their formats. Ins: "file.jpg" > Pictures
